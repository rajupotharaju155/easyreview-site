# EasyReview Marketing Site

Marketing website for **EasyReview** — an AI-powered platform that helps small businesses convert happy customers into 5-star Google reviews via QR codes, while privately capturing negative feedback.

## Stack

- React + Vite + TypeScript
- Ant Design + Tailwind CSS
- React Router
- lucide-react icons
- react-helmet-async for SEO

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
npm run lint     # ESLint + oxlint
npm run format   # Prettier
```

## Pages

- `/` — Home
- `/pricing` — Pricing
- `/faq` — FAQ

Headline variants live in `src/data/content.ts` (`HERO_HEADLINES` / `ACTIVE_HERO_HEADLINE`).
